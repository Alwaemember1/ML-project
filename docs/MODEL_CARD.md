# 模型说明

## 用途和身份

模型为ImageNet预训练ResNet18，分类头39维，训练时冻结主干及BatchNorm运行统计。网页使用原实验第3轮选定的完整检查点，不下载预训练权重。锁定SHA256为：

```text
1c464873a01b10e1dce89211859a0a9bfe1448a765ecfaef4ed57089436c6b2f
```

正常推理使用检查点中的映射及确定性预处理：EXIF方向修正、RGB、短边256、中心裁剪224、双线性插值、ImageNet均值与标准差。中文名称只用于展示，不重新编号，不校准或修改原概率，不设置拒识阈值。

## 实验记录

原实验42890张训练、9192张验证，最多10轮、patience3，实际6轮，验证loss最低第3轮。Adam、lr0.001、batch32、num_workers0、seed42，训练随机裁剪及翻转。原固定测试9192张中8567张正确，accuracy93.20%、macro F1 92.24%，详见[真实结果](RESULTS.md)。

均衡实验每类582张共22698张，实际10轮，最佳第10轮，原验证集accuracy94.92%、macro F1 94.21%；该模型没有新的最终测试，也未用于网页。训练规模、更新次数与轮次不同，不构成只改变均衡的因果实验。

## 适用范围与限制

- 类别包括26类病害/虫害、12类健康、1类背景，不是39种病害或所有农业病害。
- 预测分数不等于诊断可靠性；健康预测不能排除其他病害，背景类不能证明通用非叶片检测能力。
- 数据已排除已知SHA256字节重复，增强同源关系未排除；可能存在偏乐观评价。
- 真实拍摄、不同背景和设备的泛化未专项验证。原模型马铃薯晚疫病测试recall54.67%，不能以整体准确率掩盖弱类。
- 没有病斑严重程度、田间风险或防效标注。网页风险是透明的类别规则参考，不能说已经完成真实轻中重诊断或施药处方。

## 发布与复现

按维护者明确要求，仓库已附models/final_resnet18.pt，内容为原锁定第3轮检查点。默认相对配置为MODEL_CONFIG.json；安装依赖即可加载，错误SHA256会被拒绝。模型及其上游数据和预训练内容不自动适用原创代码的MIT许可。使用CPU与CUDA可能有数值细微差异，原模型CPU单图推理曾验证，不能将此等同所有平台已验收。

结构整理后的脚本不自动重跑旧测试。历史来源锁和source_snapshot用于追溯；重新布局可能使旧源码哈希校验拒绝评价，不能删除这一保护来重测提分。

# 数据说明

本项目使用的本地目录名为 `Plant_leave_diseases_dataset_with_augmentation`。类别下一层为图片，没有严重程度或病斑掩码标注。数据的上游来源、原图与增强链路及完整分发许可没有得到可靠确认，原始图片不进入Git，不在README虚构下载链接或可追溯原叶片分组。

已完成可读性检查：39类61486张，损坏0张。按已有SHA256选稳定字节代表后61274张参与正式实验，原副本保留。固定seed42，训练42890、验证9192、测试9192；smoke使用过的已知哈希仅在原正式训练集。已有划分清单及锁位于 `splits/formal_sha256_seed42_v1/`。

SHA256只区分字节，不排除同一叶片的旋转、翻转、裁剪版本。划分来源不能称为无增强同源泄漏，也不能由某个未经验证的文件名规则推定原图关系。

## 两种清单检查

`python -m scripts.prepare_formal_split --metadata-only` 仅校验仓库内清单的锁、类别、数量及路径/哈希交集，结果明确标记未检查外部来源和smoke归属。它不读取原图，也不代表增强同源审计或原图内容检查。

不带该选项的原严格检查还需历史来源清单、smoke清单和哈希全部可访问。仅克隆代码通常缺少这些工件；程序会拒绝，而不静默跳过。正式训练仍使用严格模式。

## 新研究与标注

复现原成绩需要完整原工件，不要只凭相同文件夹名称声称已复现。新数据应另建实验和来源记录，不覆盖旧锁。严重程度任务需要相应人工标注、病害特定分级依据及独立验证；不能用本数据集现有类别标签直接训练出经验证的轻中重模型。

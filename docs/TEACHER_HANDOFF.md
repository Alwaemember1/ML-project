# 老师交付版保留与排除建议

## 已准备的两种交付

源码仓库用于保存完整项目源码、固定划分清单、依赖、课程说明及少量真实结果。GitHub仓库已附唯一冻结模型models/final_resnet18.pt及相对路径MODEL_CONFIG.json；原始数据、其他权重、虚拟环境和历史reports目录不进入Git。完整克隆包含演示权重，仍需安装Python与依赖；课程报告和离线环境包另行交付。最新执行说明统一在根目录README。

老师演示包由 `python -m scripts.build_teacher_package` 生成，位于本地 `deliverables/`。它包含可独立推理的网页源码、一个原第3轮冻结模型、真实测试指标、课程报告和实验源码副本；不包含数据集、虚拟环境或其他实验模型。演示不依赖原始数据集和划分清单。历史训练/划分字段仅为实验追溯保留。

以下“排除”只针对交付副本；本地原件不删除、不移动。现有旧报告和模型继续保留。

## 应保留

| 内容 | 原因 |
| --- | --- |
| app.py、inference.py、smoke_utils.py、class_labels.py、plant_care.py | 网页及推理依赖；smoke_utils虽然名字含smoke，但网页仍复用它，不能删 |
| predict_image.py、启动网页.bat、.streamlit/config.toml | 命令行、启动入口及页面配置 |
| FINAL_MODEL.json及一个哈希匹配的原第3轮模型 | 完整39类映射、预处理、冻结身份和权重 |
| results/metrics.json | 页面读取的原模型真实测试成绩，不能只把数字写死在页面 |
| requirements.txt、requirements-training.txt、requirements-web.txt | 建立项目环境所需依赖版本 |
| 实验源码、固定划分锁及计数、关键日志、最佳轮次和测试证据 | 便于老师审查训练与评价过程，不能只交一个网页截图 |
| 整合报告、类别资料、演示说明及能力局限 | 用于答辩，明确第三项是类别参考风险原型 |

完整实验源码中 `train_v1.py` 依赖 `train_smoke.py` 的Dataset、训练循环和冻结检查。虽然名为smoke，删除会破坏复用关系。若将来重构，应先迁移公共函数并验证，本次不大规模重构。

## 不放进老师演示包或Git

| 内容 | 处理建议 |
| --- | --- |
| .venv/ | 不复制虚拟环境；目标机器按依赖文件创建环境。不同电脑直接复制环境不可靠 |
| __pycache__/、*.pyc、CUDA缓存、下载缓存 | 可重新生成，交付副本排除 |
| .idea/、.codex/、.agents/、.env、密钥 | 本机IDE/工具状态或可能包含凭据，Git忽略 |
| 六万张原图 | 演示包不需要；老师若要复现实验，按课程和数据授权另行提供，原图仍在本地 |
| smoke检查点、其他轮次best、last、均衡模型、ImageNet缓存 | 演示只保留原第3轮冻结模型；其他模型本地归档，不覆盖或删除 |
| 浏览器profile、上传临时文件、服务器stdout/stderr、历史截图与失败重试记录 | 演示包排除；保留必要的最终验收结论，完整开发档案留在本地 |
| 多份旧报告、重复ZIP | 老师主报告只指向整合终稿；旧版本本地留档，不混作最新结果 |

## 本轮已做的交付优化

1. 完善.gitignore，排除IDE、工具状态、凭据、其他权重、压缩包和交付输出；仅放行已发布的models/final_resnet18.pt。
2. 推理模块支持相对冻结记录的模型/指标路径。原项目绝对路径仍兼容，原FINAL_MODEL.json及模型不变。
3. 老师包内使用 `models/final_resnet18.pt`、`results/metrics.json`，复制到其他项目目录仍能定位文件。
4. 固定划分文件在Git中保持原始字节，避免换行转换破坏SHA256清单锁。
5. 当前批处理和Streamlit配置均为8601端口。旧实验文档中的8501属于历史记录，当前启动优先看根目录说明及批处理输出。
6. 打包脚本拒绝覆盖已有输出，记录文件哈希并检查ZIP完整性；没有改预测类别、概率、阈值或预处理。

## 仍建议优化的内容

- 演示版文案可进一步简化，将技术术语放入折叠说明；本轮不改变已有模型能力描述。
- 首次部署仍需Python与依赖环境。目标机未预装时提前安装测试，不能认为双击脚本会自动下载环境和权重。
- 数据增强同源关系尚未排除，真实拍摄泛化未验证；不得把测试93.20%承诺为任意上传图的可靠率。
- 严重程度和田间真实风险没有对应标注或验证，不能在交付时改写成“已完成真实轻中重诊断”。
- 老师包中的实验源码供审查；完整重训仍需恢复数据、预训练缓存和历史输入工件，不由演示入口自动执行。

本轮没有清理本机原图、旧模型或历史报告，也不重新训练、重新评价测试集或更换网页模型。
